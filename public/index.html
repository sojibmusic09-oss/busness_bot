আমাদের প্ল্যাটফর্মের ইউনিভার্সাল ক্লাউড API ব্যবহার করে সহজেই নিজস্ব Android / iOS মোবাইল অ্যাপ অথবা কাস্টম React / Next.js / WordPress ওয়েবসাইট তৈরি করতে পারবেন:

১. Authentication Headers

প্রতিটি API রিকোয়েস্টে এই দুটি হেডার পাঠাতে হবে:

Base URL: /api/v1 X-API-KEY: your_live_api_key X-SECRET-KEY: your_secret_key
২. মূল API Endpoints
GET /api/v1/products (সব পণ্য) GET /api/v1/products/search?q=watch POST /api/v1/products (নতুন পণ্য) GET /api/v1/categories (ক্যাটাগরি) GET /api/v1/inventory (স্টক রিপোর্ট)
৩. ওয়েবসাইট বা মোবাইল অ্যাপে প্রোডাক্ট লোড করার উদাহরণ (JavaScript / Fetch) 
fetch('/api/v1/products?page=1&limit=20', {
  headers: {
    'X-API-KEY': 'YOUR_API_KEY',
    'X-SECRET-KEY': 'YOUR_SECRET_KEY'
  }
})
.then(res => res.json())
.then(data => console.log('Products:', data.data));
